Calculator

A simple browser calculator built with HTML, CSS, and JavaScript as part of **The Odin Project**.

Features

* Number buttons from 0 to 9
* Addition, subtraction, multiplication, and division
* Decimal number support
* Prevents multiple decimal points in one number
* Clear button to reset the calculator
* Delete button to remove the last entered character
* Chained calculations
* Division-by-zero error handling
* Results rounded to a maximum of 7 decimal places



What I Practiced

This project helped me practice:

* Selecting DOM elements with `querySelector` and `querySelectorAll`
* Handling button clicks with event listeners
* Updating an input display with JavaScript
* Storing calculator state with variables
* Using conditionals for calculator logic
* Creating reusable functions
* Handling edge cases such as empty input, repeated decimal points, and division by zero
